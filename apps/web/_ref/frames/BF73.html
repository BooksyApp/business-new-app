Autentifikasiya

Açarınızı Authorization başlığında göndərin: Authorization: Bearer <açar>. Açar bir salona aiddir və yalnız həmin salonun məlumatını görür. Hər açarın səlahiyyətləri var; onlardan kənar çağırış 403 alır.

Limitlər

Hər açar dəqiqədə 120 çağırış edə bilər. Bundan çox olsa cavab 429 və Retry-After başlığı olur. Siyahılar limit (200-ə qədər) və offset qəbul edir.

Öz alətləriniz üçün kiçik, versiyalı REST API. Versiya 1.
Yalnız sahibAçarları və webhook-ları idarə et
Nümunə: rezerv yaratmaq
curl -X POST https://getbooqi.tech/api/v1/ext/bookings \
  -H "Authorization: Bearer bqk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "serviceId": "<xidmət id>", "staffId": "<üzv id>",
    "date": "2026-12-01", "startTime": "14:30",
    "clientName": "Nümunə Müştəri", "clientPhone": "+994501234567",
    "idempotencyKey": "order-1042" }'

Rezerv təqvimdə yaradılan rezervlə eyni qaydalara tabedir: iş saatları, istirahət və ikiqat rezerv yoxlanılır, toqquşma 409 cavabı verir. Təkrar sorğuların təhlükəsiz olması üçün idempotencyKey göndərin.

Webhook-lar

Hadisələr: booking.created, booking.updated, booking.cancelled, client.created. Hər göndəriş JSON (id, type, createdAt, data) ilə POST-dur; başlıqlar: X-Booqi-Event, X-Booqi-Delivery, X-Booqi-Timestamp, X-Booqi-Signature.
